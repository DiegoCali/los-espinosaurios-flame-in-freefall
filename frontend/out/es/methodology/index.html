03 / UN PATRÓN, CINCO IMPLEMENTACIONES

LA EVALUACIÓN DEPENDE DEL FENÓMENO.

Cada investigación define qué archivo puede modificarse, qué datos se protegen y cómo se mide la mejora. No existe una única métrica válida para las cinco.

ESTUDIO Y CONTRATOVARIABLE DE DECISIÓNRESTRICCIÓN PARTICULAR
ACME / PSI-10train.pyCPU / GITRMSE de Tad calculada (K)12 intentos; validación por jornadas y holdout final separado.
BASS-II / PSI-25research/experiment.pyHARNESS / ARCHIVOSval_score compuestoVídeo, segmentación y pronóstico; snapshots sin Git.
SAFFIRE-II / PSI-99train.pyGIT / 15 INTENTOSRMSE protegido15 intentos; validación fija sobre pocos ensayos.
SAME-R / PSI-101train.pySNAPSHOTS / 15val_score compuesto15 intentos; versiones de archivo y validación cruzada.
FLEX / PSI-69train.pyCPU / 120 SRMSE para dos objetivosPredicción de tasa y duración; máximo 2 min por candidato.

Las diferencias entre los protocolos son intencionales: todos conservan el principio de evaluar cambios con reglas previamente definidas.

05 / RESPONSABILIDAD CIENTÍFICA
